# Archive policy

Historical launchers, obsolete `config.yaml` files, MRFF/ERCTC/CMRC/NTS experiments, test-once wrappers, and machine-specific absolute-path scripts were intentionally not copied into the submission source.

They remain unchanged in the parent research workspace as provenance evidence. The submission source is limited to the frozen final method, validation evaluator, efficiency benchmark, reproducibility manifest builder, and the preregistered conv1 initialization ablation.

No historical experiment directory was deleted or rewritten during this cleanup.
