# 预注册工单：FLAME3 网络侧改进全量筛选（12 臂，30 轮三种子）

日期 2026-09-17 · 版本 v1 · 状态：待 Codex 建臂并通过工程门后执行

---

## 目的

对所有"有可能有效"的网络侧与训练侧改进做一次统一协议下的单变量筛选，挑出在**可合法判定的轴**上有真实效应的候选，为后续组合与机理研究提供依据。本工单不产生新的方法身份，不修改 v1.1（Frozen Baseline v1.1）。

## 判定轴（运行前冻结）

三条轴，每臂全部报告，判定只用前三条；Fire/Heat 侧一律**记录不判定**（val47 的 Fire 标签由机器种子锁定标注而来，不能测人类语义变化）。

| 轴 | 端点 | 指标 |
|---|---|---|
| 精度 | 人工三分类验证集 A001–A047，干净输入 | Smoke IoU、Background IoU、三类 mIoU、S；Fire/Heat IoU 与 recall 仅记录 |
| 鲁棒 | 同上，施加扰动 | 热噪声 σ = 0.02 / 0.05 / 0.10、thermal_zero、rgb_zero 下的 Smoke IoU 与 S；扰动代码复用 `evaluate_test107_posthoc.py::perturb`，不重写 |
| 效率 | 同 `RTX4090_random_stem_seed200_epoch30.json` 协议 | 参数量、GMACs、均值/P95 延迟、显存；可折叠结构按**部署形态**测 |

护栏：No-Fire 联合误报率绝对值 ≤ 0.005，且相对 v1.1 增加不超过 0.001。

### 通过规则（任一满足，且护栏通过，且 Smoke IoU ≥ v1.1 − 0.010）

- R1 鲁棒：热噪声 σ = 0.05 下 Smoke IoU 衰减比 v1.1 少 ≥ 0.030，3/3 种子
- R2 效率：GMACs 或 P95 延迟下降 ≥ 5%，精度护栏通过
- R3 精度：干净 Smoke IoU 提升 ≥ 0.020，3/3 种子；或 S 提升 ≥ 0.015，3/3 种子

未满足任一条记为"无可分辨效应"，不记为失败。**看到结果后不得调整以上任何阈值。**

## 总协议（每臂相同）

- 基线：v1.1 配置 `pidnet_s_fusion_manual_smoke_v11_30e.yaml`，逐项 diff 必须只有该臂声明的改动
- 三种子 200/201/202，30 轮，LR polynomial 总周期 100 轮，比较窗口 epoch 26–30 均值
- 数据、划分、增强、640×512、物理 batch、AMP、梯度裁剪 5.0、随机四通道 stem 初始化：全部与 v1.1 一致
- 4090 顺序运行，不并发
- 107 张 test 继续封存，本工单任何步骤不得读取

## 候选臂（按实现成本排序，即运行顺序）

| 臂 | 改动 | 实现位置 | 类别 | 预期主轴 |
|---|---|---|---|---|

| M02 | **热退化增强**：训练期热通道随机高斯噪声 σ∈[0, 0.05]、随机模糊、5% 局部 dropout；RGB 不动 | 数据增强层新增，推理无开销 | 训练增强 | 鲁棒 |
| M03 | **窄分割头**：最终 seghead 中间通道 128 → 64，辅助头与 P/I/D 不动 | `pidnet_utils.py:90` | 效率 | 效率 |

| M05 | **DWR 块**：I 分支替换一个等宽残差块为 DWR（区域卷积 + 分组不同膨胀率深度卷积 + 融合），通道数不变 | I 分支 layer3 或 layer4 中一块，二选一在预检时冻结 | 结构 | 精度 |

| M07 | **SmokeNet 矩形卷积**：I 分支替换一块为分组卷积块，通道分四组：恒等 / 1×1 / (1×7 + 7×1) 矩形 / 膨胀 3×3 | I 分支一块 | 结构 | 精度（Smoke） |
| M08 | **Ignore 感知双边界监督**：D 分支边界目标增加 Smoke 边界（Canny + 4 px 膨胀，与 Fire 相同），255 从边界 BCE 中屏蔽 | 损失与目标生成 | 监督 | 精度（Smoke 边界 F1 额外报告） |
| M09 | **clean-vs-masked 自蒸馏**：在 M01 基础上，干净输入前向作 stop-gradient 教师；人工密集像素做三分类 KL；机器部分标签区只约束 [BG+Smoke, Fire] 两组概率；仅在教师置信 ≥ 0.9 且非 Ignore 像素生效；权重固定 0.05，5 轮线性 warm-up | 损失 | 训练 | 鲁棒 |
| M10 | **双 stem 可靠性门控**：conv1 按输入通道精确拆为 RGB 支路与热支路，热支路输出乘空间门 g（轻量 conv 预测），BN 前相加；两支路用 v1.1 stem 权重切片初始化，g 初始化饱和为 1 | stem | 结构 | 鲁棒 |
| M11 | **M10 + M02**：门控与热退化增强同时 | stem + 增强 | 结构 | 鲁棒 |
| M12 | **GCNet 可重参数化块**：I 分支替换一块为 GCBlock（训练多路，部署折叠为单 3×3 卷积） | I 分支一块 | 结构 | 精度 + 效率 |

M10 / M11 与 M02 构成门控 × 增强的 2×2（M02 = 无门控有增强，M10 = 有门控无增强，M11 = 两者都有，v1.1 = 都无），归因时按 2×2 报告。

**明确排除**：完整双流编码器、RTFormer、BEVANet、PBSeg 原型解码器、Mamba/SSM 融合、更换骨干。理由：改动量超出"小改"，且与边缘约束冲突。

## 工程门（每臂训练前必须全部通过，任一失败该臂停止并记录，不阻塞其他臂）

1. 输出 shape 正确，四通道输入正确接收
2. AMP 正常，loss 与梯度有限（seed 200 跑 2 个 epoch）
3. **Ignore 不进语义损失**（构造样本断言）；边界损失合同按现有实现记录，M08 额外断言 255 不进边界 BCE
4. **partial-label 逻辑与 v1.1 一致**（同一批样本集合损失取值一致断言；M09 的额外项单独核对）
5. 零初始化臂（M06、M10、M11）：初始状态前向输出与 v1.1 **逐元素差 < 1e-6**
6. 可折叠臂（M04、M12）：训练形态与部署形态前向输出差 < 1e-4，效率按部署形态测
7. 配置逐项 diff 只含该臂声明的改动
8. 参数量与 GMACs 增量报告，任一臂增量 > 5% 需在报告中标红
9. checkpoint 可保存可恢复
10. 未读取 test107

## 运行与评估

- 阶段 0：12 臂全部过工程门（约 1 小时）
- 阶段 1：按 M01 → M12 顺序训练，每臂三种子（约 12 到 14 小时）
- 阶段 2：只读评估，每臂 best_S 与 epoch 26–30 窗口两个口径，干净 + 扰动曲线 + 效率
- 训练期异常即停：loss 发散、梯度 inf/nan、某种子 S 偏离其余两种子 > 0.15，停该臂剩余种子并记录
