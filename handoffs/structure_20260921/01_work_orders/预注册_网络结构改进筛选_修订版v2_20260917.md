## 一、目的与定位

主贡献定位为**网络结构改进**。数据集建设、标注审计、缩通道、TensorRT 等只作为实验可信度保障或工程对照，不计入创新。

工作分两层：

1. **借鉴验证层**：在统一协议下单变量筛选结构候选，确认哪些机制在当前网络上有可分辨效应
2. **针对性设计层**：围绕有效机制提出自拟结构，用消融说明设计理由

本工单不修改 v1.1（Frozen Baseline v1.1），不产生新的方法身份；通过筛选的臂进入设计层后另行预注册。

## 二、判定轴与规则（运行前冻结，看到结果后不得调整）

### 2.1 端点与指标

| 轴 | 端点 | 指标 |
|---|---|---|
| 精度 | 人工三分类验证集 A001–A047，干净输入 | Smoke IoU、Background IoU、三类 mIoU、S |
| 鲁棒 | 同上，施加扰动 | 热噪声 σ = 0.02 / 0.05 / 0.10、thermal_zero、rgb_zero 下的 Smoke IoU 与 S。扰动代码复用 `evaluate_test107_posthoc.py::perturb`，不重写 |
| 效率 | 同 `RTX4090_random_stem_seed200_epoch30.json` 协议 | 参数量、GMACs、均值 / P95 延迟、显存；可折叠结构按部署形态测 |

**Fire/Heat 侧一律记录不判定。** 原因：val47 的 Fire 标签由锁定机器种子标注得到，与温度阈值���构性共线，无法测量人类语义上的变化。Fire 侧判定须等从零起标的验证集 v2 建成后另行执行。

### 2.2 ���算上限

- GMACs 增幅 ≤ 15%（相对 v1.1 的 7.47 GMACs）
- RTX 4090 部署形态 P95 延迟 ≤ 10 ms（v1.1 为 7.72 ms）
- 超出上限的臂照常训练评估，但不能进入设计层

### 2.3 护栏

- No-Fire 联合误报率绝对值 ≤ 0.005，且相对 v1.1 增加 ≤ 0.001
- 干净 Smoke IoU ≥ v1.1 − 0.010

### 2.4 通过规则（护栏通过，且任一满足）

- **R1 鲁棒**：热噪声 σ = 0.05 下 Smoke IoU 衰减比 v1.1 少 ≥ 0.030，3/3 种子
- **R2 精度**：干净 Smoke IoU 提升 ≥ 0.020，3/3 种子；或 S 提升 ≥ 0.015，3/3 种子
- **R3 效率**：GMACs 或 P95 下降 ≥ 5% 且精度护栏通过（仅工程对照臂适用，不计创新）

未满足任一条记为"无可分辨效应"，不记为失败。

## 三、总协议（每臂相同）

- 基线：v1.1 配置 `pidnet_s_fusion_manual_smoke_v11_30e.yaml`；逐项 diff 必须只含该臂声明的改动
- 三种子 200/201/202，30 轮，LR polynomial 总周期 100 轮，比较窗口 epoch 26–30 均值；同时报告 best_S 口径
- 数据、划分、增强、640×512、物理 batch、AMP、梯度裁剪 5.0、随机四通道 stem 初始化：全部与 v1.1 一致
- 4090 顺序运行，不并发；训练期异常即停（loss 发散、梯度 inf/nan、某种子 S 偏离其余两种子 > 0.15）
- 107 张 test 全程封存

## 六、执行顺序

### 阶段 0：设计筛选（交用户审批后再实现）

每臂提交：结构图、接入位置、参数与 GMACs 预估、与历史方案差异、预期主轴。用户批准后进入阶段 1。

### 阶段 1：工程门（每臂训练前，任一失败该臂停止，不阻塞其他）

1. 输出 shape 正确，四通道输入正确接收
2. AMP 正常，loss 与梯度有限（seed 200 跑 2 轮）
3. Ignore 不进语义损失（构造样本断言）；B1 额外断言 255 不进边界 BCE
4. partial-label 逻辑与 v1.1 一致（同批样本集合损失取值一致断言）
5. 零初始化臂（R2、R3）：初始前向与 v1.1 逐元素差 < 1e-6
6. 可折叠臂（S1、S2）：训练形态与部署形态前向差 < 1e-4；效率按部署形态测
7. 配置逐项 diff 只含声明改动
8. 参数量与 GMACs 增量报告；超过 2.2 预算的标红
9. checkpoint 可保存可恢复
10. 未读取 test107

### 阶段 2：第一批训练（一晚）

S1、S3、S4、S6 + R1、R2、R3 + B1 + E1，共 9 臂，三种子 30 轮。结构臂与鲁棒臂正交，可同批。

### 阶段 3：只读评估与第一批报告

三条轴全部报告，按 2.4 判定；R1 / R2 / R3 / v1.1 做 2×2 归因；报告交用户。

### 阶段 4：第二批（需用户依据第一批报告批准，不自动启动）

S2、S5、S7、S8。

### 阶段 5：针对性设计层（另行预注册）

**主设计假设 H-A：边界条件化的上下文尺度选择。** D 分支边界特征不只在末端融合使用，而是作为可学习条件参与 I 分支局部与大范��语义特征的选择；保留原始特征路径，边界估计错误时不强行抑制。消融：无条件 / 边界条件 / 随机条件。

**对照假设 H-B：方向与尺度分通道处理。** 局部细节、横纵方向上下文、多尺度语义分配给不同通道组后融合；与普通卷积、S3、S4 单独使用分别对照。H-B 为 S3 与 S4 的组合形式，只作为消融对照，不单独宣称创新。

设计层的组合规则：每次只加一个通过的臂；组合臂同样三种子 30 轮、同一判定规则。

### 阶段 6：最终确认

组合后仍通过的进入 100 轮精确恢复，相同多种子，单模块与组合消融。短训练领先不作为最终有效的依据。Fire 侧判定须等验证集 v2 建成。
